SECURE LOG SANITIZATION

Remove sensitive data from diagnostic logs without uploading your files.

SanitizeLog detects sensitive information such as passwords, authentication tokens, and other configured secrets and replaces them with deterministic security tokens directly in your browser.

No upload Your diagnostic content stays in your browser.
No registration No account or server-side storage is required.
Deterministic Repeated values receive consistent replacement tokens.

    HOW IT WORKS

    Your diagnostic content stays on your device

    SanitizeLog is designed around local processing. The browser performs the sanitization operation without sending the diagnostic content to a remote processing service.

    01

    Provide your logs

    Paste diagnostic output into the input area or load a local diagnostic file.

    02

    Apply security rules

    The selected security profile scans the content using its configured sanitization rules.

    03

    Generate sanitized output

    Detected sensitive values are replaced with deterministic security tokens while preserving the surrounding diagnostic structure.

    PRIVACY BY DESIGN

    Diagnostic content is processed locally

    SanitizeLog is designed so the sanitization engine runs inside your browser. This makes it suitable for sensitive diagnostic logs that should not be unnecessarily uploaded to a third-party processing service.

    • No account required
    • No diagnostic log upload required
    • No server-side sanitization dependency
    • Browser Web Worker processing
    • Deterministic token replacement
